# Roam India — Day 6 project

This project includes the existing frontend prototype plus a new `server/` backend starter.

- Open `index.html` with VS Code Live Server to view the frontend.
- Read `server/README.md` for MySQL setup, API startup and endpoint tests.
- The frontend is still demo-only and stores its demo account/booking state in localStorage. The new API is separate until Day 7 integration.

Do not collect real customer details or deploy this as a production booking service yet.
